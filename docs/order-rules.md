# Правила заявок

Все значения и компоненты синтетические.

- Цена и количество должны быть положительными.
- Notional равен `price * quantity`.
- Максимально допустимый notional — **1 000 000 USD включительно**. Значение ровно на границе должно приниматься.
- Matching engine выбирает bid с наибольшей ценой. При одинаковой цене побеждает заявка с наименьшим `created_at`.
- Market data snapshot считается stale, когда `now - updated_at >= stale_after`. По умолчанию порог равен 2 секундам.
